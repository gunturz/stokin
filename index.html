☁️ Database Supabase Penyimpanan Lokal

Hubungkan ke cloud Supabase agar data stok tersimpan di PostgreSQL cloud dan tersinkronisasi otomatis di Android & iPhone.

📌 Cara Menghubungkan Supabase:
  1. Buka dashboard supabase.com > buat project baru.
  2. Buka menu SQL Editor > jalankan skrip dari supabase_schema.sql.
  3. Buka Project Settings (⚙️) > API > salin Project URL & anon public key lalu tempel di atas.

📱 Tambahkan StokIn ke Layar Utama

Akses cepat tanpa browser, responsif seperti aplikasi asli, dan tetap bisa dibuka saat offline.

Pasang StokIn di Layar Utama iPhone / iPad

  1. Ketuk tombol Bagikan (Share) pada bilah bawah Safari.
  2. Gulir menu ke bawah lalu pilih "Tambah ke Layar Utama" (Add to Home Screen) ➕.
  3. Ketuk "Tambah" di pojok kanan atas.
